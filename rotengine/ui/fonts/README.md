Bundled fonts (all free to redistribute):

- `mono10x20.png`, `mono12x24.png`: DejaVu Sans Mono 2.37 pre-rendered into
  CP437 tilesheets by `tools/make_fonts.py` (Bitstream Vera / public-domain
  license, see `DejaVu-LICENSE.txt`). The default `mono` / `mono-large` fonts.
- `dejavu12x12_gs_tc.png`, `dejavu16x16_gs_tc.png`: DejaVu rendered as square
  libtcod tilesheets (TCOD layout), from the python-tcod / libtcod font set.
  Used by `--font square12` / `--font square16`.
